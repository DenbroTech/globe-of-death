# Globe of Death

Phone-first 3D rhythm motorbike stunt game (three.js r128 + Vite).

```bash
npm install
npm run dev        # http://localhost:5173 — also reachable from a phone on the same Wi-Fi
npm run build      # static build in dist/
npm test           # headless play-test (needs `npm run dev` running)
```

See `CLAUDE.md` for the game design, code map and working notes.
`original/globe-of-death.html` is the single-file version this project was split from.
